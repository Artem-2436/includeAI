# 🌟 IncludeAI

**IncludeAI** — это современное, легкое и безопасное веб-приложение для общения с искусственным интеллектом, созданное на базе передовой модели **Qwen**. 

Интерфейс приложения выполнен в уникальном премиальном стиле **White & Gold (Тихая роскошь)** и полностью адаптирован для использования как на компьютерах, так и на мобильных устройствах.

---

## 🚀 Главная фишка: Архитектура BYOK (Bring Your Own Key)

В отличие от большинства коммерческих ИИ-оболочек (таких как Perplexity или Jasper), **IncludeAI** использует децентрализованную архитектуру:
* В исходном коде приложения **нет зашитых API-ключей**. 
* Пользователи используют свой собственный бесплатный токен доступа от **Hugging Face Inference API**.
* **Абсолютная безопасность:** Введённый токен сохраняется исключительно в локальной памяти устройства пользователя (`localStorage`) и никогда не передается на сторонние сервера.
* **Неограниченное масштабирование:** Благодаря отсутствию центрального сервера, приложение способно без сбоев обслуживать миллиарды запросов в секунду — каждый пользователь общается с ИИ напрямую через свой токен.

---

## 💎 Основные возможности (Фичи)

* **Премиальный UI/UX:** Минималистичный бело-золотой дизайн, разработанный с нуля.
* **Адаптивное «Бургер-меню»:** Выдвижная боковая шторка (Sidebar) для управления настройками и историей чатов без захламления экрана мобильного телефона.
* **Подключение «на лету»:** Индикатор статуса API (`API подключён ✓`) прямо в интерфейсе.
* **Over-the-Air Updates (OTA):** Приложение развернуто через **GitHub Pages**, что позволяет обновлять интерфейс и логику на устройствах пользователей мгновенно в реальном времени, минуя долгие модерации в магазинах приложений.
* **Кроссплатформенность:** Работает как полноценное PWA-приложение, устанавливаемое в один клик на главный экран смартфона.

## 🛠️ Технологический стек

Проект написан без использования тяжелых фреймворков для обеспечения максимальной скорости работы:
* **HTML5** — семантическая структура приложения.
* **CSS3 (Flexbox/Grid)** — адаптивная верстка, кастомные градиентные тени и плавные анимации выезда шторки.
* **Vanilla JavaScript** — асинхронные запросы (`fetch`) к серверам Hugging Face, обработка интерфейсной логики и работа с `localStorage`.
* **GitHub Pages** — хостинг статического веб-сайта.
